# Doubly Linked Lists

Python examples of nodes connected in both directions using `next` and `prev`.

- [doubly_linked_list.py](doubly_linked_list.py): Creates three linked nodes and traverses forward and backward.
- [push_back.py](push_back.py): Adds nodes to the end while updating the head, tail, and links.
- [add_before.py](add_before.py): Inserts a new node before an existing node in the list.
- [remove_node.py](remove_node.py): Removes a middle node by reconnecting its neighbors.
- [pop_back.py](pop_back.py): Empty placeholder for a future example.

Each completed file runs independently and prints its example results.
